# Contact Manager

A simple command-line contact manager made with Python.

The program allows the user to add, view, search, edit, and delete contacts. Contacts can also be saved to and loaded from a JSON file.

## How It Works

The user chooses an option from the menu.

- Add a new contact with a name, phone number, and email.
- View all saved contacts.
- Search for a contact by name.
- Edit an existing contact.
- Delete a contact.
- Save contacts to a JSON file.
- Load contacts from a JSON file.
- The program handles invalid menu input.
- The program handles missing contact files.
